# Smart Parking 2.0

Automata-Based Parking & Access Control Simulator for a Finite Automata & Formal Languages ISE.

## Included
- DFA vehicle-number validator
- NFA path simulation
- Regular Expression laboratory
- DFA transition table
- Live parking state machine
- Parking capacity finite-state model
- Payment automaton
- Security/error detection FSM
- Activity log
- Report generation
- Print / Save as PDF
- JSON report download
- Responsive UI

## Run locally
Open `index.html` in a browser.

## Host on GitHub Pages
1. Create a GitHub repository, e.g. `smart-parking-2`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to Settings → Pages.
4. Select Deploy from branch → `main` → `/ (root)`.
5. Save and open the generated GitHub Pages URL.

No backend or database is required.
